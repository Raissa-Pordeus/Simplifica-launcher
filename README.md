# Simplifica Launcher 📱

Uma interface web simplificada projetada para reduzir a exclusão digital e a complexidade no uso de smartphones por idosos. Desenvolvido como projeto final da disciplina de IA Generativa na UFCG.

## 🎯 O Problema
As interfaces padrões de smartphones possuem ícones pequenos, baixo contraste e exigem gestos complexos, causando toques acidentais e frustração.

## ✨ Funcionalidades (MVP)
Atendendo às necessidades reais mapeadas nas entrevistas em campo:
- **Acessibilidade Visual:** Fontes extra-grandes e modo de alto contraste para usuários com dificuldades visuais (como histórico de catarata).
- **Foco em Comunicação:** Atalho direto e simplificado para o WhatsApp de familiares.
- **Botão SOS:** Disparo rápido de uma mensagem de emergência pré-configurada para o WhatsApp.
- **Prevenção de Erros:** Ausência de menus ocultos ou rolagem de tela para evitar toques acidentais.

## 🛠️ Tecnologias e Uso de IA
- **HTML/CSS:** Estruturação da interface web responsiva e acessível.
- **GitHub Pages:** Hospedagem direta do protótipo.
- **NotebookLM:** Utilizado para a análise e síntese das transcrições das entrevistas com os usuários.
- **Prompt Engineering & Vibe Coding:** Construção iterativa do código e geração da identidade visual (avatares e ícones) utilizando modelos generativos.
